## Run Locally

This is a static website built with HTML, CSS, and JavaScript. Open `index.html` in a browser, or use the VS Code Live Server extension.

## Deploy with GitHub Pages

1. Open the repository's **Settings → Pages**.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select the `main` branch and `/(root)`, then save.
4. GitHub Pages will provide the public website URL after deployment completes.
