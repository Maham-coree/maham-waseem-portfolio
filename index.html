RETAIL INVENTORY SYSTEM
01 / FEATURED PROJECTACADEMIC PROJECT

Retail Inventory & Sales Intelligence System

A database-driven application for managing stock across stores, recording sales, tracking stock movements and identifying products that need reordering.

PythonFastAPIPostgreSQLSQLAlchemyAlembicJWTHTML / CSS / JS
Explore problem, features & my work

Problem addressed

Small shops can lose sales when stock runs out unexpectedly or tie up money in slow-moving inventory. This project provides a structured way to monitor stock and plan replenishment.

Key functionality

  • Store-level inventory and stock status tracking.
  • Sales recording with automatic stock updates and protection against negative stock.
  • Supplier, purchase order and stock movement management.
  • Reorder recommendations and reporting.
  • Role-based access for admin, manager and cashier.
  • Database learning labs covering SQL, transactions and query plans.

My learning

Applied DBMS concepts including relational design, keys, normalization, SQL queries, transactions and API-to-database workflows.
